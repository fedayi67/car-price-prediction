# 🚗 Car Price Prediction Using Machine Learning

## Project Overview

This project develops a machine learning model for predicting the selling price of used cars based on their characteristics and specifications.

The project covers the complete machine learning workflow, including:

- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Feature preprocessing
- Machine learning model development
- Model evaluation and comparison
- Final model training
- Model deployment using a Dash web application
- Docker containerization

The final application allows users to enter vehicle information through a web interface and receive an estimated selling price. Users may also leave some input fields empty, as the deployed model includes missing-value imputation.
